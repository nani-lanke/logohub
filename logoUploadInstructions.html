Logo Size Guide

Before uploading your logo, make sure it's the right shape and size. Check the guide below to see what works!

Square Square Logo — Same Width & Height

A square box needs a square logo. That means the width and height of your image must be exactly the same — for example, 200×200 pixels. If your logo is wider or taller on one side, it won't fit correctly and you'll get an error. Think of it like a square peg in a square hole — it only works when the shape matches!

✅ Correct
Width = Height
❌ Too Wide
Width ≠ Height
❌ Too Tall
Width ≠ Height

Rectangle Rectangle Logo — Wider Than Tall

A rectangle box needs a wide logo. The width must be bigger than the height — but not more than twice as wide (for example, 240×160 px is perfect, but 400×80 px is too stretched). If your logo is square or taller than it is wide, it won't work for this box type.

✅ Correct
Width > Height
❌ Too Tall
Height > Width
❌ Too Square
Width = Height

Vertical Vertical Logo — Taller Than Wide

A vertical box needs a tall logo. The height must be bigger than the width — but not more than twice as tall (for example, 150×220 px works great). Logos that are square or wider than tall will not fit this box type. Think of a tall phone screen — your logo should look like that!

✅ Correct
Height > Width
❌ Too Square
Width = Height
❌ Too Wide
Width > Height

Mini Mini Logo — Tiny Square

A mini box is a very small square, so your logo must also be a perfect square (width = height). Even though the box is tiny, the shape rule is the same as the normal square box. Use a small, neat, square logo — like an app icon or favicon!

✅ Correct
Width = Height
❌ Too Wide
Width ≠ Height
❌ Too Tall
Height > Width
