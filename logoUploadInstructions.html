Logo Size Guide

fit the box.

Before uploading your logo, make sure it's the right shape for the box you picked. Find your box type below to see what works.

Square box

Same width and height

Rule
Width = Height
Example
200 × 200 px

A square box needs a square logo. The width and height of your image must be exactly the same. If your logo is wider or taller on one side, it won't fit correctly and you'll get an error. Think of a square peg in a square hole: it only works when the shape matches.

CorrectWidth = Height
Too wideWidth ≠ Height
Too tallWidth ≠ Height

Horizontal (rectangle) box

Wider than tall

Rule
Width > Height, max 2×
Example
240 × 160 px

A horizontal box needs a wide logo. The width must be bigger than the height, but not more than twice as wide. For example, 240×160 px is perfect, but 400×80 px is too stretched. If your logo is square or taller than it is wide, it won't work for this box type.

CorrectWidth > Height
Too tallHeight > Width
Too squareWidth = Height

Vertical box

Taller than wide

Rule
Height > Width, max 2×
Example
150 × 220 px

A vertical box needs a tall logo. The height must be bigger than the width, but not more than twice as tall. For example, 150×220 px works great. Logos that are square or wider than tall will not fit this box type. Think of a tall phone screen: your logo should look like that.

CorrectHeight > Width
Too squareWidth = Height
Too wideWidth > Height

Mini box

A tiny square

Rule
Width = Height
Example
Like an app icon

A mini box is a very small square, so your logo must also be a perfect square. Even though the box is tiny, the shape rule is the same as the normal square box. Use a small, neat, square logo, like an app icon or favicon.

CorrectWidth = Height
Too wideWidth ≠ Height
Too tallHeight > Width

Before you upload

Quick checklist

  • PNG, JPG or WebP

    Other file types can't be uploaded.

  • Smaller than 1 MB

    Shrink or compress big images before you upload them.

  • Looks good on white

    Logos sit on a white background, so transparent PNGs will show white behind them.
